# Очевидно

База материалов для подготовки к контрольным, коллоквиумам и экзаменам. Markdown + LaTeX, строгая чёрно-белая тема со светлым и тёмным режимами, умный поиск по всем материалам и поиск внутри материала, оглавление с отслеживанием прокрутки.

Деплой — GitHub Pages через Actions (`.github/workflows/deploy.yaml`).

## Как добавить материал

1. Положите markdown-файл в папку `content/`, например `content/matan/kolloquium-2.md`.
   Формулы пишутся в LaTeX. Поддерживаются оба стиля делимитеров: `$x^2$` и `\(x^2\)` для строчных формул, `$$ ... $$` и `\[ ... \]` для выключных. Также работают GFM (таблицы, чек-листы, сноски), сырой HTML и KaTeX-окружения (`aligned`, `cases`, `pmatrix` и т.д.).
2. Добавьте запись в `content/manifest.json` в нужный предмет:

```json
{
  "id": "matan-kolloquium-2",
  "title": "Коллоквиум 2. Интегралы",
  "type": "colloquium",
  "file": "matan/kolloquium-2.md"
}
```

Название материала берётся из `title`, поэтому не обязательно дублировать его заголовком `# ...` в самом файле — можно начинать сразу с разделов `## ...`. Первый заголовок H1 всё равно попадёт в оглавление, просто на странице он появится дважды.

3. Закоммитьте и запушьте в `main` — сайт пересоберётся сам.

Поля материала:

| Поле    | Обязательное | Описание                          |
| ------- | ------------ | --------------------------------- |
| `id`    | да           | уникальный идентификатор (латиница) |
| `title` | да           | название карточки                 |
| `type`  | да           | ключ из `types` (см. ниже)        |
| `file`  | да           | путь к md-файлу относительно `content/` |

Типы материалов задаются в `types` манифеста: `colloquium`, `exam`, `lectures`, `other` — можно дописывать свои.

Если предмет новый, добавьте его в `subjects`:

```json
{
  "id": "fizika",
  "name": "Физика",
  "description": "Механика, термодинамика, оптика.",
  "materials": []
}
```

Порядок материалов на сайте — как в манифесте.

## Картинки

Файлы кладите в `public/images/...` и ссылайтесь из markdown как `/images/имя.png`. Путь с ведущим `/` автоматически подстроится под адрес GitHub Pages.

## Локальный запуск

```bash
npm install
npm run dev
```

Сборка и предпросмотр:

```bash
npm run build
npm run preview
```

## Деплой на GitHub Pages

1. Запушьте репозиторий на GitHub (ветка `main`).
2. В настройках репозитория: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. После пуша в `main` workflow сам соберёт и опубликует сайт. Каждый следующий пуш обновляет сайт.

Дополнительная настройка не нужна: `base: './'` в `vite.config.js` уже учитывает любой путь репозитория.

## Технологии

- React 19 + Vite
- react-markdown, remark-gfm, remark-math, rehype-katex (KaTeX), rehype-raw, rehype-slug
- mark.js — поиск с подсветкой внутри материала
- github-slugger — якоря и оглавление
- lucide-react — иконки

## Структура

```
content/
  manifest.json        структура: предметы → материалы, типы
  <предмет>/*.md       сами материалы
src/
  lib/                 загрузка контента, поиск, роутер, тема
  components/          UI
.github/workflows/deploy.yaml
```
